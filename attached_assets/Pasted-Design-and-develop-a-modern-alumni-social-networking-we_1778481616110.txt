Design and develop a modern alumni social networking website with a minimal, clean, monochrome design language. The platform should feel professional, simple, lightweight, and easy to use on both desktop and mobile devices.

CORE DESIGN STYLE:

* Monochrome only (black, white, gray shades)
* Extremely clean UI with lots of spacing
* Modern typography
* Minimal distractions
* Fast-loading interface
* Mobile-first responsive design
* Soft borders and subtle shadows
* No unnecessary animations
* Inspired by a mix of LinkedIn, Reddit, and modern minimalist dashboards

TARGET USERS:

* Current students
* Alumni / graduated students
* Recruiters and companies

PRIMARY FEATURES:

1. AUTHENTICATION

* Sign up/login using:

  * Google authentication
  * Email authentication
* Simple onboarding flow
* User selects:

  * Current student
  * Alumni
  * Recruiter/company

2. USER PROFILE SYSTEM
   Each user can create and edit their own profile.

Profile includes:

* Full name
* Profile picture
* University/college
* Department
* Graduation year
* Current role/company
* Skills
* Bio/about section
* Social links (LinkedIn/GitHub optional)
* Resume upload (PDF)
* Privacy controls

Profiles should be searchable.

3. SOCIAL FEED
   A simple community feed where users can:

* Create text posts
* Upload images/documents
* Like posts
* Comment on posts
* Share experiences, advice, career journeys, opportunities, and memories

Feed should prioritize readability and simplicity.

4. MESSAGING SYSTEM
   Users can message any other user.

Messaging has TWO MODES:
A. Normal Messaging
B. Anonymous Messaging

Inbox UI must contain TWO TABS:

* Main
* Anonymous

Anonymous messaging requirements:

* Sender identity hidden
* Receiver does not see sender name/profile
* Anonymous messages clearly labeled
* Anti-spam protection
* Ability to block/report anonymous senders

5. CAREERS SECTION
   Dedicated careers page with TWO TABS:

TAB 1: Student CVs

* Students/alumni upload resumes/CVs
* Recruiters can browse/search
* Filters by department, graduation year, skills

TAB 2: Job Listings

* Companies/recruiters post job opportunities
* Include:

  * Job title
  * Company
  * Location
  * Description
  * Apply link/email
  * Internship/full-time tags

6. ADMIN PANEL
   Minimal admin dashboard to:

* Moderate posts
* Remove spam
* Ban users
* Review reports
* Manage anonymous messaging abuse

7. TECH STACK REQUIREMENTS
   Use free-tier friendly technologies that can scale later.

Preferred stack:
Frontend:

* Next.js
* Tailwind CSS

Backend:

* Supabase

Hosting:

* Vercel

Authentication:

* Supabase Auth with Google OAuth

Database:

* PostgreSQL via Supabase

Storage:

* Supabase Storage

Architecture should be scalable for future growth.

8. PERFORMANCE REQUIREMENTS

* Fast loading
* SEO-friendly
* Secure authentication
* Optimized database queries
* Responsive UI
* Accessible design

9. UI PAGES
   Include:

* Landing page
* Login/signup page
* Home feed
* Profile page
* Edit profile page
* Messaging page
* Careers page
* Job detail page
* Admin dashboard
* Notifications dropdown
* Search page

10. LANDING PAGE COPY STYLE
    Tone:

* Professional
* Warm
* Community-focused
* Trustworthy

Possible headline:
“Where students and alumni stay connected.”

Subheadline:
“Share experiences, build careers, and help the next generation grow.”

11. FUTURE SCALABILITY
    Structure the project so future features can be added easily:

* Mentorship matching
* Events
* Alumni groups
* University verification
* AI recommendations
* Mobile app

12. IMPORTANT PRODUCT GOALS
    The platform must:

* Feel lightweight and calm
* Encourage genuine interaction
* Be easy for non-technical users
* Avoid clutter
* Focus on community and careers
* Be realistic to build using free-tier infrastructure initially

Generate:

* Full UI/UX design
* Database schema
* Component structure
* API architecture
* Responsive layouts
* Suggested folder structure
* Modern reusable components
* Clean dashboard interfaces
* Complete homepage design
* Messaging interface design
* Careers portal design
* Authentication flow
* Dark monochrome theme system
